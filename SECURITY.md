# Security

Please report vulnerabilities through a private
[security advisory](https://github.com/jarvis-jhk/baba-port/security/advisories/new),
not a public issue. Relevant areas: loading levels, level packs and level
codes from the internet, importing save files and game-data zips (Android),
and online sessions (Warpzone peer messages). Issues in Warpzone itself go
to [its project](https://github.com/jarvis-jhk/warpzone/security/advisories/new).

Release archives list their SHA-256 sums in `SHA256SUMS`; the Android APK is
signed with the project's release key.
